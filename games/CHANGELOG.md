# 更新履歴

バージョンは `version.js` の `APP_VERSION` で管理します(`0.メジャー.修正`)。
公開するたびに、ここへ1〜2行追記し、GitHub でタグ(例 `v0.3.0`)を付けておくと戻しやすくなります。

## 0.9.24

- PLAY押下時の表示を「読み込み中…」に変更

## 0.9.23
- 設定画面を並べ替え: ノーツ速度 / タイミング調整 / スコア表示 / スコア表示方式 / オート / 等速 / 同時押しライン / ミラー / コンボ演出 / FAST・LATE / フリック指離し / フレームレート / 軽量描画 / FPS表示 / ノーツSE・音量 / プレイヤー名 / ユーザーデータ
- 開発者モード以外では「楽曲ごとの音量自動調整=常にON」「スコア送信=常にON」「キー表示=常にOFF」で固定し、設定からも非表示
- ダウンロードデータは、PLAYを押したときにオンラインなら更新を確認し、あれば「追加データがあります」を表示(ダウンロード/あとで)。設定画面のダウンロードデータ欄は開発者モード限定に

- SE音声ファイルの読み込み・書き出しは開発者モード限定に
