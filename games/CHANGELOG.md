# 更新履歴

バージョンは `version.js` の `APP_VERSION` で管理します(`0.メジャー.修正`)。
公開するたびに、ここへ1〜2行追記し、GitHub でタグ(例 `v0.3.0`)を付けておくと戻しやすくなります。

## 0.6.1
- 譜面保管所に「譜面一覧」表示を追加(小節を縦に積んで列に並べた楽譜風。タップ/フリック/ロング/スライド/中継点/ダメージ、4・8・16小節/列)

## 0.6.0
- AUTOプレイ中は判定表示が「AUTO」になり、リザルトの判定枠は「AUTO使用のため判定されませんでした」と表示
- 選曲画面で、選んでいる曲の試聴を再生(シートの hue1=開始秒 / hue2=終了秒、前後フェード・ループ。空欄なら曲の20%地点から15秒)
- 選曲画面に「譜面保管所」を追加(曲・難易度ごとのBPM/コンボ数/ノーツ種別/密度グラフ/JSON表示・コピー)
- hue1・hue2 は色ではなくなりました(ジャケット未設定時の背景色は曲idから自動)

## 0.5.0
- 設定画面の右側に、現在のノーツ速度で落ちる1レーンの「速度確認」を追加(設定を変えるとすぐ反映)
- 「音に合わせてタイミング調整」を追加: クリック音に合わせてタップ → ズレの中央値を「タイミング調整」に自動反映

## 0.4.5
- スコア送信先(Apps Script)のURLをアプリに埋め込み

## 0.4.4
- 設定シートをApps Script経由でも読めるように(書式に影響されず、文字の値が欠けない)。送信先URL(SAVE_URL_DEFAULT か save.url)があれば優先して使う

## 0.4.3
- 設定シートが読めなかった理由を画面に表示(取得エラー / 共有設定 / 見出しなし+読めた先頭行)
- 色など文字の値が空で届いたときの警告(Google側の「数値と文字が混在する列」の仕様対策)
- スコア送信先を index.html の SAVE_URL_DEFAULT に直接書けるように

## 0.4.2
- 設定シートのタブ名を柔軟に: settings / setting / Settings / Setting / 設定 / 設定シート / config のどれでも読める

## 0.4.1
- スコア送信の診断を追加: リザルト画面に記録されない理由を表示 / 設定画面に「スコア送信先を確認」ボタン / 送信エラーの内容を表示

## 0.4.0
- スコア保存: リザルト確定時に、スプレッドシートの3枚目「scores」へ記録(Apps Script経由)。オフライン時は端末に溜めて自動再送
- 設定シートに `save.url`(送信先)と `rules.version`(ルールの版)を追加。設定画面に「プレイヤー名」「スコア送信」を追加

## 0.3.0
- バージョン管理を `version.js` に一本化(タイトル表示・キャッシュ更新が連動)
- 新しいバージョンが公開されたとき、アプリ内に「更新」通知を表示

## 0.2.1
- スライド始点の「始点だけクリティカル(headCrit)」を判定・SE・スコア集計・色に反映

## 0.2.0
- スプレッドシートの2枚目(settings)で、判定幅・スコア配分・ノーツSE・見た目を管理
- データURL(曲シート)をアプリに埋め込み
- デモ曲を削除

## 0.1.0
- PWA対応(ホーム画面に追加・オフライン起動)
- スプレッドシート読み込みの強化(見出し行の自動検出、行数表示、警告)
